Sigil · sigil-mcp · v0.2.0

Ask your AI-security posture
in plain language.

Sigil measures the guard surface of your AI coding agents (hooks, permissions, sandbox, MCP allowlists). With sigil-mcp, Claude reads that posture over the Model Context Protocol and reasons about it with you — no dashboard to learn, just a conversation.

read-only measures, doesn't block 9 MCP tools OSS · Apache-2.0

01The leap

Same fleet data — a different way to consume it.

Before — a static dashboard

Open a web console, scan a fleet table, eyeball which host is red, click into rows. You read; the tool shows.

After — an agentic analyst

Ask "what's risky and why?" Claude calls the fleet tools, ranks hosts, explains the reasons, and proposes next actions. You ask; the agent reasons.

02How it connects

A thin, read-only bridge — the agent stays a deterministic data plane.

05Try it yourself

Ships in v0.2.0 — five binaries, one curl.

1 · Install (adds sigil-mcp alongside sigil, sigil-sender, sigil-server, sigil-sign):

curl --proto '=https' --tlsv1.2 -fsSL https://raw.githubusercontent.com/Ju571nK/sigil/main/install.sh | sh

2 · Register with Claude Code (point it at your sigil-server's read API — directly on :8443, or a bearer-only reverse proxy):

claude mcp add sigil-fleet \
  -e SIGIL_SERVER_BASE_URL=http://your-server:9090 \
  -e SIGIL_SERVER_READ_TOKEN=your-read-token \
  -- ~/.local/bin/sigil-mcp

(Claude Desktop: add the same command + env to mcpServers in claude_desktop_config.json.)

3 · Ask — in a new session:

fleet에서 가장 위험한 호스트를 찾고, 왜 위험한지 reasons를 풀어서 설명해줘
ju571n의 AI guard 상태를 요약하고 우선 조치 3가지를 제안해
지난 24시간 alert를 트리아지해줘

What's next. Today this reads a sigil-server's fleet API. A planned sigil-mcp local mode would read the local agent's control socket directly — so a single developer can ask Claude "what's my AI risk?" with no server at all (issue #55).
